# ADR-003: Shared Featured Structure

## Status
Approved

## Context
Our application needs to be able to be maintainable. React is know for becoming Spaghetti quite fast.

## Decision
We are going to be using a Shared / Feature structure in order to fix the Spaghetti.

## Alternatives
Component based structure

Rejected due to risk of Spaghetti.
Rejected as we don't know each other in our team. We need it to be as efficient as possible.

## Consequences
- A little more knowledge / setup is needed in order to start coding compared to normal structure.
- Folder structure must be in focus and always on top. Never change unless accepted by the entire team.
- Developers must decide if a feature is a feature or a shared feature.
