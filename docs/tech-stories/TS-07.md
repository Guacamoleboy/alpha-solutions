## Technical Story 07 - Support Staff Capacity Calculations

As a development team, we need a reliable way to calculate Pickelball staff capacity, so that the Owner Dashboard can show whether the available staff can support the current demand.

## Acceptance Criteria

- [ ] A staff resource can have a configured maximum number of courts and members it can support.
- [ ] The system can calculate the number of booked courts and members for a selected period.
- [ ] The system can calculate the total capacity of the available staff resources for that period.
- [ ] The system can compare the booked courts and members with the available staff capacity.
- [ ] The system identifies when the available capacity is not enough.
- [ ] The system provides the current demand, capacity and shortfall to the Owner Dashboard.
- [ ] The calculation uses the same booking and staff resource data as the rest of the application.

## Sub-issues

- Add staff capacity values for courts and members.
- Calculate booked courts and members for a selected period.
- Calculate total available staff capacity.
- Compare demand and capacity and calculate any shortfall.
- Provide the resource status for the Owner Dashboard.
- Verify the calculation with cases where capacity is enough and not enough.
