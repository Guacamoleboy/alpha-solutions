## Technical Story - Teststrategi

Som udviklingsteam vil vi udarbejde en teststrategi, så vores 
testindsats fokuserer på de vigtigste krav og kvalitetsrisici.

## Acceptkriterier

- [ ] Centrale krav og kvalitetsrisici i systemet er identificeret. 
- [ ] Det er begrundet, hvilke testniveauer der er relevante.
- [ ] Relevante testtyper er valgt og begrundet. 
- [ ] Det er vurderet, hvilke tests der bør automatiseres, og hvilke der med 
fordel kan udføres manuelt (jf. testpyramiden).
- [ ] Strategien relaterer til det konkrete system

## Sub-issues

- [TESTING] Identify the system's central requirements and quality risks.
- [TESTING] Select and justify the relevant test levels and test types.
- [TESTING] Decide which tests should be automated and which are better performed manually, using the test pyramid.
- [TESTING] Document a test strategy that is specific to this system.
