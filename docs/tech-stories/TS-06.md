## Technical Story 06 - Automate Build, Test and Deployment

### Description

As a development team, we want an automated CI/CD pipeline that builds, tests and deploys the frontend and backend, so that changes can be delivered safely without manual deployment steps.

### Acceptance Criteria

- [ ] The CI pipeline runs the frontend and backend builds and automated tests on every push.
- [ ] A successful build and test run on the `main` branch starts the deployment process.
- [ ] The frontend is built before it is deployed.
- [ ] The backend is built before it is deployed.
- [ ] The project's automated tests run before deployment.
- [ ] A failed build or test prevents the affected application from being deployed.
- [ ] A successful run on `main` deploys the new frontend version automatically.
- [ ] A successful run on `main` deploys the new backend version automatically.
- [ ] Each pipeline run shows a visible success or failure status.
- [ ] A clean commit on `main` can complete the build, test and deployment process without manual build or deployment steps.

### Sub-issues

- Configure the CI workflow to run frontend and backend builds and tests on every push.
- Configure the pipeline to start deployment only after a successful run on `main`.
- Configure the frontend build and deployment job.
- Configure the backend build and deployment job.
- Prevent deployment when the affected build or tests fail.
- Show the status of each pipeline run.
- Verify the complete process from a clean commit on `main`.
