## Definition of Done

An issue (US / TS) is considered Done when all applicable criteria below have been fulfilled:

- Acceptance Criteria have been fulfilled.
- Code follows the agreed project code standards.
- Relevant unit and/or integration tests have been implemented and pass successfully.
- No known critical bugs or issues remain.
- Relevant documentation has been updated where necessary.
- The changes have been merged into the correct branch.
- The implementations has been reviewed through a Pull Request.
