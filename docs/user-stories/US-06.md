## User Story 06 - Monitor Pickelball Staff Resources

As a Pickelball facility owner, I want to see the available staff resources and the current Pickelball demand in the Owner Dashboard, so that I can identify when more resources are needed.

## Acceptance Criteria

- [ ] The owner can view the available staff resources in the Owner Dashboard.
- [ ] The owner can view the number of booked courts and members for a selected period.
- [ ] The system uses each staff member's configured capacity for courts and members when showing the resource status.
- [ ] The dashboard shows whether the available staff capacity is enough for the booked courts and members.
- [ ] The dashboard clearly shows when additional staff resources are needed.
- [ ] The owner can see how many courts or members are beyond the available staff capacity.
- [ ] The resource overview updates when bookings, members or available staff resources change.

## Sub-issues

- Add support for staff capacity for courts and members.
- Calculate the current demand from booked courts and members for a selected period.
- Compare the current demand with the available staff capacity.
- Identify when the available staff capacity is not enough.
- Build the resource overview in the Owner Dashboard.
- Show the number of courts or members beyond the available capacity.
- Update the overview when bookings, members or available staff resources change.
