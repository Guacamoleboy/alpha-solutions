## User Story 11 - Reset a Forgotten Password

As a Pickelball member, I want to reset my password when I have forgotten it, so that I can regain access to my account.

## Acceptance Criteria

- [ ] The member can select a "Forgot password" option from the login page.
- [ ] The member can enter their email address and date of birth to identify their account.
- [ ] The member can access the password reset form when the entered email address and date of birth match their account.
- [ ] The member can enter a new password and repeat it for confirmation.
- [ ] The password is reset when the new password and repeated password match.
- [ ] The member cannot reset the password when the new password and repeated password do not match, and receives a clear message.
- [ ] The password reset flow does not require an email to be sent.
- [ ] After a successful reset, the member can use the new password to log in.

## Sub-issues

- Add a "Forgot password" option to the login page.
- Allow the member to provide their email address and date of birth.
- Verify the provided account information before allowing a password reset.
- Provide fields for a new password and repeated password.
- Show a clear message when the passwords do not match.
- Reset the member's password after successful confirmation.
- Allow the member to log in with the new password.
