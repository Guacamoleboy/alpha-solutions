## User Story 10 - Reserve Courts for Specific Events

As a Pickelball facility owner, I want to reserve specific courts for events on specific dates, so that court availability reflects events such as birthdays, parties and bachelor parties and members cannot book courts that are reserved for an event at the given date or time.

## Acceptance Criteria

- [ ] The owner can create an event reservation for a specific date.
- [ ] The owner can select one or more courts for the event reservation.
- [ ] The event reservation can be managed from the "Åbningstider" area or from a separate "Events" area.
- [ ] The owner can view the event name, date and courts included in an event reservation.
- [ ] A court reserved for an event is unavailable for member bookings for the reserved date and event period.
- [ ] The owner can change or remove an event reservation.
- [ ] Changes to or removal of an event reservation update the availability shown to members.
- [ ] The member should have an "Event" option aswell do showcase if they have any events planned.
- [ ] Event reservations use the events described in US-08 and do not change the facility's recurring opening hours.

## Sub-issues

- Support event reservations for specific dates and time periods.
- Allow the owner to select one or more courts for an event reservation.
- Provide an area under "Åbningstider" or a separate "Events" area for managing event reservations.
- Show the event name, date and reserved courts to the owner.
- Prevent members from booking courts reserved for an event.
- Support changing and removing event reservations.
- Update member court availability when event reservations change.
- Connect court reservations to the events described in US-08 without changing recurring opening hours.
