## User Story 10 - Process Event Booking Requests

As a Pickelball facility owner, I want to review and process event booking requests, so that I can confirm suitable events and keep court availability accurate for members.

## Acceptance Criteria

- [ ] The owner can view submitted event booking requests and their status.
- [ ] The owner can view each request's event name, date, time period, number of guests, requested courts, equipment requirement and co-organizers.
- [ ] The owner can change a request's status from `Pending` to `Confirmed` or `Denied`.
- [ ] A confirmed request is treated as an event reservation for the requested date and time period.
- [ ] The owner can select the specific courts reserved for a confirmed event.
- [ ] Courts reserved by a confirmed event are unavailable for member court bookings during the event period.
- [ ] A denied request does not reserve courts for the event.
- [ ] The member can see the updated request status after the owner confirms or denies it.
- [ ] The owner can change or remove a confirmed event reservation.
- [ ] Changes to or removal of a confirmed event reservation update the court availability shown to members.
- [ ] Event reservations do not change the facility's recurring opening hours.

## Sub-issues

- [FRONTEND] Provide the owner with an overview of event booking requests and their statuses.
- [BACKEND] Provide the request details needed for the owner to process an event booking request.
- [FRONTEND] Allow the owner to confirm or deny a pending request.
- [BACKEND] Update the request status and make the result visible to the requesting member.
- [BACKEND] Create a court reservation when an event request is confirmed.
- [FRONTEND] Allow the owner to select the specific courts reserved for a confirmed event.
- [BACKEND] Prevent member court bookings from using courts reserved by a confirmed event.
- [BACKEND] Do not reserve courts for denied requests.
- [FRONTEND] Allow the owner to change or remove a confirmed event reservation.
- [BACKEND] Update member court availability when a confirmed reservation changes or is removed.
- [BACKEND] Keep event reservations separate from recurring opening hours.
