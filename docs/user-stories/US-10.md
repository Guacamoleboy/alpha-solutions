## User Story 10 - Manage Event Requests and Reservations

As a pickleball facility owner, I want to review and process member event requests and create approved events, so that events are managed consistently and court availability stays accurate for members.

## Acceptance Criteria

- [x] The owner can view event requests and events in a dedicated dashboard, search by title or email, and filter by status.
- [x] The owner can view an event's name, date and time period, guest count, organizer email, co-organizers, equipment requirement and event code.
- [x] The required court count is calculated automatically as one court per four guests, rounded up. Members and owners cannot enter the court count manually when creating an event.
- [x] The owner can confirm or deny a pending member request. The dashboard displays and filters `Pending`, `Confirmed`, `Passed` and `Denied` statuses; `Passed` is a displayable event status and is not set through the current owner actions.
- [x] When a member request is confirmed, the system randomly assigns the required number of active courts that are available for the event's date and time.
- [x] If too few courts are available, confirmation is stopped and the owner is notified that the event cannot be held.
- [x] The owner can create an event directly. Owner-created events are confirmed automatically and receive the same automatic court allocation.
- [x] A denied event has no court reservations. Denying an already confirmed event removes its reservations and makes those courts available again.
- [x] Members can see their event's updated status. Confirmed events can be expanded to show assigned courts; events in other statuses do not expose the court dropdown.
- [x] The owner can edit event details and save the changes. Confirmed events receive an updated random allocation based on the edited guest count and time period.
- [x] Event reservations prevent overlapping member bookings on the reserved courts. Changing or removing an event reservation updates court availability.
- [x] Event reservations do not change the facility's recurring opening hours.

## Sub-issues

- [x] [FRONTEND] Provide an owner event dashboard with status, search and filtering controls.
- [x] [FRONTEND] Show event details, co-organizers, equipment, event code and assigned courts to the owner.
- [x] [FRONTEND] Allow the owner to confirm or deny member requests and create approved events directly.
- [x] [FRONTEND] Calculate and display the required court count from guest count without allowing manual entry.
- [x] [BACKEND] Provide event request data and persist owner changes to event details and status.
- [x] [BACKEND] Automatically assign available courts to confirmed and owner-created events, and reject allocation when capacity is insufficient.
- [x] [BACKEND] Prevent member bookings from overlapping confirmed event court reservations.
- [x] [BACKEND] Remove court reservations when an event is denied and keep reservations separate from recurring operating hours.
- [x] [FRONTEND] Let members view updated event statuses and expand confirmed events to see assigned courts.
