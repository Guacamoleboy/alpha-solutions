## User Story 03 - Find and Choose a Court

As a Pickelball member, I want to see and choose a court on a 2D map, so that I can select a court that suits me and is available when I want to play.

## Acceptance Criteria

- [ ] The member can open a 2D map that shows all courts and their relative positions.
- [ ] Each court can be identified by its existing unique number and name.
- [ ] The 2D map shows the direction and surface type of each court.
- [ ] The member can select an individual court and choose a date and time period to see its availability.
- [ ] The availability shown for a court matches the availability used when making a booking.
- [ ] The map shows which courts the member has booked before.
- [ ] The map shows which courts the member has marked as favourites.
- [ ] If no court is available for the selected date and time period, the member sees a clear message.

## Sub-issues

- Add the court position, direction and surface type needed for the 2D map.
- Provide court availability for a selected date and time period.
- Provide the member's previous court bookings and favourite courts.
- Build the 2D court map and show each court's number, name and information on it.
- Let the member select a court and view its availability.
- Mark previously booked and favourite courts on the map.
- Use the same availability data for the map and the booking flow.
- Show a clear message when no court is available.
