## User Story 13 - Close a Court for a Specific Time

As a pickleball facility owner, I want to close a specific court for a chosen date and time period, so that I can make it unavailable when the facility needs to reserve it for other purposes.

## Acceptance Criteria

- [x] The owner can select one specific court and choose a date and time period to close it.
- [x] The owner can choose start and end times in full-hour increments within the facility's operating hours for the selected date.
- [x] The owner can select a description for the closure, such as maintenance, cleaning, an event or other.
- [x] The owner can save the closure and see which court and time period have been closed.
- [x] Members cannot book the selected court during the closed time period.
- [x] The selected court remains available for booking outside the closed time period, subject to its other existing availability.
- [x] A closure for one court does not make other courts unavailable.
- [x] After attempting to save a closure, the owner receives a clear message indicating whether it was successful.

## Sub-issues

- [x] [FRONTEND] Let the owner select a court, date and time period for a closure.
- [x] [BACKEND] Save the closure for the selected court and time period.
- [x] [FRONTEND] Show the owner the court and time period covered by each closure.
- [x] [BACKEND] Use the facility's operating hours for the selected date when determining valid closure times.
- [x] [BACKEND] Make the selected court unavailable to member bookings during the closure.
- [x] [BACKEND] Keep other courts and times unaffected by the closure.
- [x] [FRONTEND] Show the owner a clear success or failure message after saving a closure.
- [x] [FRONTEND] Keep start and end time choices visible and offer full-hour options based on the selected date's operating hours.
- [x] [FRONTEND] Let the owner choose a description for the closure.
- [x] [BACKEND] Save the selected closure description.
