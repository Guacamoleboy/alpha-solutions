## User Story 04 - Owner Administration Portal

As the owner of the pickleball center, I want to have access to an administration portal, so that I can manage the pickleball center through one central place without having to know programming.

## Acceptance Criterion

- [x] The owner can access a dedicated administration portal after logging in with an owner account.
- [x] The administration portal provides the owner with access to the administrative functions available to the owner role.
- [x] The owner can navigate between the available administrative functions from the administration portal.
- [x] Only users with the owner role can access the administration portal.
- [x] The owner can access administrative functions without needing direct access to the backend or database.
- [x] The administration portal can be extended with additional administrative functions as new requirements are introduced.
- [x] The owner receives appropriate feedback when an administrative action is successfully completed.
- [x] The owner receives appropriate feedback when an administrative action cannot be completed.
