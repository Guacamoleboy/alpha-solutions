## User Story 08 - Manage Pickelball Event Resources

As a Pickelball facility owner, I want to assign staff resources to special events, so that events such as birthdays, parties and bachelor parties have the staff they need.

## Acceptance Criteria

- [ ] The owner can create or view a Pickelball event that needs staff resources.
- [ ] The owner can assign one or more staff resources to an event.
- [ ] The owner can change the staff resources assigned to an event.
- [ ] The owner can remove a staff resource from an event.
- [ ] The event shows its current staff resources after an assignment is added, changed or removed.
- [ ] The system shows when the event does not have enough staff resources according to the configured staff capacity.

## Sub-issues

- Add support for Pickelball events that need staff resources.
- Support assigning staff resources to an event.
- Support changing and removing staff resources from an event.
- Show the current staff resources for each event.
- Check the event's staff need against the configured staff capacity.
- Show a clear warning when an event does not have enough staff resources.
