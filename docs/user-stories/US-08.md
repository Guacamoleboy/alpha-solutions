## User Story 08 - Request a Pickelball Event

As a Pickelball member, I want to request an event booking and add other members as co-organizers, so that I can plan an event with other members and receive a decision from the facility.

## Acceptance Criteria

- [ ] The member can submit an event booking request with the event name, date and time period.
- [ ] The member must specify the number of guests and the number of courts requested for the event.
- [ ] The member can specify whether equipment is needed for the event.
- [ ] The member can add one or more co-organizers by entering their email addresses.
- [ ] A person can only be added as a co-organizer when the email address belongs to a member with a membership.
- [ ] The member cannot add a non-member as a co-organizer and receives a clear message explaining why.
- [ ] A newly submitted event booking request has the status `Pending`.
- [ ] The member can view the event request and its current status: `Pending`, `Confirmed` or `Denied`.
- [ ] The member can see the requested guests, courts, equipment choice and co-organizers on the event request.
- [ ] The event request is not treated as a confirmed booking until the owner confirms it.

## Sub-issues

- [FRONTEND] Provide a form for creating an event booking request with its name, date and time period.
- [BACKEND] Store the requested number of guests, courts and equipment requirement.
- [FRONTEND] Allow the member to add co-organizers by email address.
- [BACKEND] Verify that each co-organizer has a membership before adding them to the request.
- [FRONTEND] Show a clear error when an email address does not belong to a member.
- [BACKEND] Set newly submitted event requests to `Pending`.
- [BACKEND] Support the `Pending`, `Confirmed` and `Denied` request statuses.
- [FRONTEND] Show the event request details, co-organizers and current status to the member.
- [BACKEND] Keep a request unavailable for booking until the owner confirms it.
