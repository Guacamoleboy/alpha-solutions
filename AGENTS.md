# AIDA Agents Instructions

This file provides instructions for AI coding agents working with the AIDA codebase.

For detailed project overview, architecture, coding guidelines, and validation steps, see the [Agent Instructions](.github/agent-instructions.md).

# Contribution guidelines

CONTRIBUTING.md defines the project's contribution standards.

When reviewing whether current changes follow the contribution guidelines, use:

[Review Contributing](.agents/skills/review-contributing/SKILL.md).

The review-contributing skill is advisory only. It provides input to the developer and must not modify files, generate implementation code, generate tests, or apply fixes.
