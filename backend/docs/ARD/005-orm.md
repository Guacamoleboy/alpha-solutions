# ADR-005: Object-Relational Mapping (orm)

## Status
Approved

## Context
The backend application needs a consistent way to map Java objects into a database.
Our solution should integrate with Javalin and PostgreSQL.

## Decision
We are going to be using JPA / Hibernate as our ORM implementation. It's known in the development team and it's fairly
easy to set up and get going fast.

Entities and relations will be mapped simply by running the application - from code.

## Alternatives
N/A

## Consequences
- Java entities can be mapped straight into our database.
- Common database operations can be handled efficiently using CRUD.
- JPA works well with Spring / Javalin.
- Complex or sensitive operations still need additional setup but that's to be expected.
- The team must understand relationships and ORM behavior specific for JPA / Hibernate and how to edit and operate those.
